## The line

> The barista renamed me Kevin.

29 characters, one line, no setup notes, no explanation. A coffee order turns into an identity reassignment: the barista decides who you are, and the new name sticks.

## How it works

`main.ts` (Node 22, standard library only) writes the line above to `/output/entry.txt` (or `$ENTRY_OUTPUT` when set). That is the whole program — the joke is the entry.
